# Filo Platform v1.28.20 güncelleme notu

Bu paket v1.28.19 tam kaynak üzerine uygulanır.

## Kritik düzeltmeler

- Ortam bayrakları büyük/küçük harften bağımsız ve güvenli biçimde değerlendirilir.
- Sağlayıcı dispatch işlemleri AAL2/MFA korumasına alındı.
- Üretim public signup yalnız doğrulanmış Supabase oturumu ve güncel hukuki kabul makbuzuyla tenant oluşturur.
- MFA faktörü kaldırmak için güncel AAL2 oturumu zorunludur.
- Operasyon scheduler'ı 100'den fazla tenantı dönen pencereyle işler.
- Final kanıt doğrulaması symlink kaçışını ve yetersiz görev ayrılığını reddeder.

## Kurulum

1. ZIP'i temiz bir klasöre açın.
2. İçeriği v1.28.19 proje köküne kopyalayın ve aynı adlı dosyaları güncelleyin.
3. Bağımlılıkları kilit dosyasına göre kurun.
4. `npm run typecheck`, `npm run lint`, `node --test tests/*.test.mjs`, `npm run security:scan` ve `npm run migration:lint` komutlarını çalıştırın.
5. Hedef ortama göre `npm run build` veya `npm run build:vercel` çalıştırın.

Gerçek hesap, cihaz, hukuk, pilot ve üretim kanıtı bulunmadıkça yayın kararı `NO-GO` olarak kalır.
