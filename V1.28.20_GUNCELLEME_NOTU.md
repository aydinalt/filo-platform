# Filo Platform v1.28.20 güncelleme notu

Bu paket v1.28.19 tam kaynak üzerine uygulanır.

## Kritik düzeltmeler

- Ortam bayrakları büyük/küçük harften bağımsız ve güvenli biçimde değerlendirilir.
- Sağlayıcı dispatch işlemleri AAL2/MFA korumasına alındı.
- Üretim public signup yalnız doğrulanmış Supabase oturumu ve güncel hukuki kabul makbuzuyla tenant oluşturur.
- MFA faktörü kaldırmak için güncel AAL2 oturumu zorunludur.
- Operasyon scheduler'ı 100'den fazla tenantı dönen pencereyle işler.
- Final kanıt doğrulaması symlink kaçışını ve yetersiz görev ayrılığını reddeder.
- Supabase çalışma zamanında istemciden gelebilecek `oai-authenticated-*` başlıkları yok sayılır; kimlik yalnız doğrulanmış Supabase oturumundan alınır.
- Vercel/Supabase PostgreSQL uyumluluk katmanı gerçek veritabanına karşı entegrasyon testiyle doğrulanır.
- Cloudflare Sites ve Vercel yapıları CI içinde ayrı ayrı derlenir.
- Mobil sürücü ve telematik gateway bağımlılıkları kilitlendi; tip, Expo Doctor ve gateway kabul testleri CI kapsamına alındı.
- Kök uygulama, mobil uygulama ve gateway için ayrı CycloneDX SBOM üretilir.
- API'nin beklenmeyen iç hata ayrıntıları istemciye açılmaz; izlenebilir olay kimliği döndürülür.
- Tam kaynak ve güncelleme ZIP'leri yalnız temiz Git commit'i ve doğrulanmış sürüm manifesti üzerinden oluşturulur.

## Kurulum

1. ZIP'i temiz bir klasöre açın.
2. İçeriği v1.28.19 proje köküne kopyalayın ve aynı adlı dosyaları güncelleyin.
3. Kök dizinde, `mobile-driver/` altında ve `services/telematics-gateway/` altında bağımlılıkları ilgili kilit dosyasına göre `npm ci` ile kurun.
4. `npm run typecheck`, `npm run lint`, `node --test tests/*.test.mjs`, `npm run security:scan` ve `npm run migration:lint` komutlarını çalıştırın.
5. `npm run typecheck --prefix mobile-driver`, `npm run doctor --prefix mobile-driver` ve `npm test --prefix services/telematics-gateway` komutlarını çalıştırın.
6. Cloudflare Sites hedefi için `npm run build`, Vercel/Supabase hedefi için `npm run build:vercel` çalıştırın.
7. PostgreSQL bağlantısı bulunan doğrulama ortamında `npm run supabase:runtime:test` çalıştırın.

ZIP içindeki `outputs/release-manifest.json` dosyasında `release` alanı `1.28.20`, `dirty` alanı `false` ve `commit` alanı dağıtılan kaynak commit'i olmalıdır. Yanındaki `.sha256` dosyası ZIP bütünlüğünü doğrular.

Gerçek hesap, cihaz, hukuk, pilot ve üretim kanıtı bulunmadıkça yayın kararı `NO-GO` olarak kalır.
