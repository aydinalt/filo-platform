# Filo Platform v0.16 güncellemesi

Bu sürüm tenant güvenli filo raporlarını, 366 günle sınırlandırılmış tarih/araç filtrelerini ve audit kayıtlı CSV dışa aktarımını ekler.

1. Güncellenen dosyaları mevcut proje klasörünün üzerine kopyalayın.
2. `npm install` ve `npm run db:migrate` çalıştırın.
3. `npm run typecheck`, `npm test` ve `npm run build` ile doğrulayın.
