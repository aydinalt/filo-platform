# Local update v0.90

This release delivers tenant onboarding and account access as one connected launch pack.

- Adds self-service company and owner account creation.
- Records versioned terms and privacy acceptance evidence.
- Adds tenant-bound, one-time, seven-day member invitations.
- Stores only invitation token digests and supports preview, acceptance and revocation.
- Creates the invited user, membership and first session atomically.
- Adds owner-only member disable/reactivate controls.
- Revokes all active tenant sessions when member access is disabled.
- Adds onboarding, invitation and access audit events.
- Adds web registration, invite acceptance and member access management views.
- Adds one migration and no file deletion.
