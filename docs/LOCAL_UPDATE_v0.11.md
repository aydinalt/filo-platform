# Local Update v0.11

## Scope

- Vehicle document and compliance records
- Traffic insurance, casco, inspection, registration and other document types
- Expired and 30-day expiry warnings
- Renewed/cancelled lifecycle with RBAC and audit events

## Apply

1. Copy the update package over the v0.10 project.
2. Run `npm install`.
3. Run `npm run db:migrate`.
4. Run `npm run typecheck`, `npm test`, and `npm run build`.
