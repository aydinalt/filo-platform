# Yerel Güncelleme — v0.17

Bu sürüm uygulama içi Aksiyon Merkezi'ni ekler. Geciken bakım ve belgeler ile açık kusur, yüksek/kritik güvenlik olayı ve açık kaza dosyalarından yinelenmeyen görevler üretir. Manuel görev, tenant içi sorumlu atama, öncelik, son tarih, durum ve audit kayıtları desteklenir.

## Kurulum

1. Güncellenen dosyaları proje köküne kopyalayın.
2. `npm install`
3. `npm run db:migrate`
4. `npm run typecheck`
5. `npm test`
6. `npm run build`

E-posta, SMS ve push gönderimi bu sürümün kapsamında değildir.
